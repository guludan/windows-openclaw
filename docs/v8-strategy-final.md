## 三、行业破净密度补贴

行业标签已写入 `industry_components_ths_l1.bk_density_level`

| 密度等级 | 标准 | SMA折扣 | PB加严 |
|---------|------|---------|--------|
| **RARE** (1-10%) | 破净罕见 = 强信号 | 阈值×0.8 | 无 |
| **NORMAL** (10-50%) | 均值回归主力 | 标准阈值 | 无 |
| **DENSE** (>50%) | 破净常见 = 低价值 | 标准阈值 | 需PB<0.5 |

### 关键行业举例

**RARE（一梯队弹药库，SMA阈值×0.8）：**
小金属、化学制药、通用设备、自动化设备、半导体、医疗器械
→ 数据支撑：1-10%密度行业平均T+20=+19.09%，胜率79.7%

**DENSE（三梯队老破大，PB<0.5才生效）：**
银行、钢铁、房地产、建筑装饰、环境治理
→ 数据支撑：>50%密度行业平均T+20仅+3.24%，PB<0.5才有+5.05%

## 四、入场流程（信号生成逻辑）

```
for each stock:
    if phase == HI_EQ: skip
    
    # 确定牛熊模式（按年度标签或动态检测）
    regime = get_market_regime()
    
    # 查行业密度
    density = industry_map[code].bk_density_level  # RARE/NORMAL/DENSE
    
    # 基础SMA阈值
    threshold = MATRIX[regime][phase]
    
    # 行业补贴：RARE降低SMA要求
    if density == 'RARE' and pb < 1:
        threshold *= 0.8
    
    # 检查SMA偏离
    if sma_dev < -threshold:
        # 重资产加严：DENSE行业需要更深的PB破净
        if density == 'DENSE' and pb >= 0.5:
            skip
        elif density == 'DENSE' and pb < 0.5:
            ENTRY_SIGNAL(pb_ultra_low=True)
        elif pb < 1:
            ENTRY_SIGNAL()
```

## 五、离场策略（压力位分批）

基于SMA动态均值做压力位，不再固定T+5/T+20：

| 压力位 | 触发条件 | 动作 |
|-------|---------|------|
| P1: 情绪修复 | 股价反弹至SMA-5% | 卖出1/2 |
| P2: 价值回归 | 股价反弹至SMA-0%（即SMA均值线）| 清仓 |

**例外：** A_RECOVER/A_ACCUM阶段可持有至SMA+5%（趋势溢价）
