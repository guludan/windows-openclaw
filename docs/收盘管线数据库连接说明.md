### 连接串（DSN）

```
host=192.168.3.14 dbname=guludan user=guludan password=toto
```

Python（psycopg2）写法：

```python
import psycopg2

DB = 'host=192.168.3.14 dbname=guludan user=guludan password=toto'
conn = psycopg2.connect(DB)
```

命令行（psql）：

```bash
psql "postgresql://guludan:toto@192.168.3.14:5432/guludan"
```

## 二、前置条件

1. **必须处于同一局域网**。`192.168.3.14` 是内网地址，外网无法直连；
   WSL 环境下需要能 ping 通工控机。
2. 工控机的 PostgreSQL 需允许局域网访问：
   - `postgresql.conf` → `listen_addresses = '*'`
   - `pg_hba.conf` → 允许 `192.168.3.0/24` 段 md5/scram 认证
3. 账号权限：`guludan` 用户**无 SUPERUSER 权限**，
   不能 `CREATE DATABASE`、不能 `CREATE EXTENSION`。
   需要建库/装扩展请用工控机本地 postgres 超级用户操作。

验证连通性：

```bash
nc -zv 192.168.3.14 5432
python3 -c "import psycopg2; print(psycopg2.connect('host=192.168.3.14 dbname=guludan user=guludan password=toto').status)"
```

## 五、注意事项

1. **数据不到不跑报告**。脚本如果连不上库会静默失败或用旧数据，
   写报告前必须先确认最新数据日期。
2. **不要高频批量拉外部接口**（AKShare 禁批量，易封 IP）。
3. 数据库连接串在脚本里是硬编码的，改密码要同步改所有引用：
   ```bash
   grep -rn "192.168.3.14" scripts/ --include="*.py"
   ```
4. 所有写操作前建议先备份：`scripts/auto_backup.sh`。

## 六、故障排查

| 现象 | 排查方向 |
|------|---------|
| `could not connect to server` | 工控机是否开机 / 网络是否同网段 / `nc -zv` 测端口 |
| `password authentication failed` | 密码是否被改；`pg_hba.conf` 认证方式 |
| `permission denied for database` | 用了非 `guludan` 用户或权限被收回 |
| 连接成功但查询为空 | 数据未更新到当日，检查管线日志 |
| WSL 下超时 | 检查 WSL 网络模式（NAT 模式需能路由到 192.168.3.x） |
