# 逆推框架设计文档 — 弱势方量化反制体系

> **立场声明**：A股本质上是政策市+国有经济融资工具，规则设计天然偏袒信息优势方（机构、产业资本、国家资金）。作为弱势方，我们不试图预测"合理价格"，而是通过数据痕迹逆推强势方的操作意图，在他们的收割周期中找到生存空间。

---

## 一、核心假说：酸碱中和模型 v2

### 1.1 基本框架

每个股票/市场存在两个能量池：
- **[B]（多头能量）** — 持有利好信息、获利盘、增量资金
- **[A]（空头能量）** — 利空信息、套牢盘、流出资金

当 [B] > [A] 时价格上涨，反之下跌。**关键在于：这些能量是有主语的。**

### 1.2 能量归属（N的阶级性）

同一事件（如"政策利好"）对不同阵营意义完全不同：

| 阵营 | 信息来源 | 行为模式 | 可观测痕迹 |
|------|---------|---------|-----------|
| 🏦 **机构** | 卖方研报、产业调研、与上市公司沟通 | 提前建仓→媒体吹票→高位出货 | 龙虎榜机构席位、大宗交易折溢价 |
| 🎣 **游资** | 技术分析、散户心理、跟风情绪 | 快速建仓→拉升造势→砸盘出货 | 龙虎榜营业部集中买入/卖出 |
| 🌊 **北向资金** | 全球宏观、地缘政治、汇率 | 趋势性流入/流出，偏中长期 | 沪深港通十大成交股 |
| 🏛️ **国家队/国投** | 政策意图、市场稳定需求 | 逆周期操作，护盘/托底 | ETF份额变化、银行股异动 |
| 👨 **散户** | 社交媒体、新闻、技术指标 | 滞后跟风，高位接盘 | 换手率异常、股吧热度 |

### 1.3 R指数（心理距离/信息密度）

$$R = \frac{1}{\alpha \cdot \text{vol\_norm} + \beta \cdot \text{diverge\_norm}}$$

- **R大** → 市场分歧大、心理距离远 → 多空博弈充分，尚未形成方向共识
- **R小** → 市场一致性极强 → 要么加速上涨，要么即将反转（踩踏前兆）

**关键预警信号：** R从高值（>5）快速收缩到低值（<2），往往意味着一个强势方完成了方向引导，另一方正在被收割。

## 二、逆推信号体系

### 2.1 一级信号（直接观测）

| 信号 | 数据源 | 关联阵营 | 频率 |
|------|--------|---------|------|
| 龙虎榜买入/卖出前五 | `lhb_trader` | 机构/游资/北向 | 日级 |
| 龙虎榜净买入 | `lhb_daily` | 全市场 | 日级 |
| 机构买卖统计 | `lhb_inst` | 机构 | 日级 |
| 营业部排名 | stock_lhb_traderstatistic | 游资 | 日级 |
| 北向成交十大 | （现有北向金额信号） | 外资 | 日级 |
| 大宗交易 | 待接入 | 机构/产业资本 | 日级 |
| 限售解禁 | 待接入 | 产业资本 | 日级 |

### 2.2 二级信号（计算合成）

| 信号 | 公式 | 含义 |
|------|------|------|
| 机构浓度 | 机构净买额 / 总龙虎榜成交额 | 机构参与度 |
| 游资活跃度 | 知名游资营业部上榜频率 | 短线资金热度 |
| [B]/[A]浓度 | 涨跌比×(1+涨跌幅) | 多空能量平衡 |
| R指数 | 1/(截面σ归一化+涨跌比偏离度) | 心理距离/信息密度 |
| 阵营分歧度 | 机构净买入 vs 游资净买入 差异 | 见下文详述 |

### 2.3 三级信号（交叉推理）

#### 阵营分歧度（Key Indicator）

当**机构**和**游资**的方向相反时，这是最有价值的信号：

- 🟢 **机构买入 + 游资卖出** → 机构在低位吸筹，游资离场 → 中期看多信号（但短期可能继续跌）
- 🔴 **机构卖出 + 游资买入** → 机构高位出货，游资接力 → 风险信号，接近顶部
- ⚪ **机构买入 + 游资买入** → 共识性高 → 加速方向，但持续性短
- ⚫ **机构卖出 + 游资卖出** → 双杀 → 可能加速下跌

#### 信息流匹配

将每日的重要新闻/政策事件归类到对应阵营的"N"池：

$$
N_{\text{阵营}} = \sum (\text{事件重要性} \times \text{与该阵营利益相关度})
$$

然后对比 **N流入量** 与 **该阵营的资金行为** 是否一致：
- **一致**：该阵营按预期操作（如政策利好→机构买入）
- **不一致**：可能存在未公开信息或操纵行为

## 三、收割周期模型

根据A股常见操作模式，划分典型收割周期：

### 3.1 机构标准周期

```
Phase 1: 潜伏期（1-3个月）
├── [B]缓慢积累，[A]稳定
├── R指数从中位（3-4）开始下降
├── 对应数据：机构席位零星买入，大宗交易折价<3%
└── N信号：产业政策扶持方向，卖方研报开始覆盖

Phase 2: 拉升期（2-4周）
├── [B]快速上升，[A]降至低位
├── R指数冲到高位（>5），涨跌比>70%
├── 对应数据：机构席位持续净买入，龙虎榜机构浓度上升
└── N信号：媒体密集报道，政策文件落地

Phase 3: 出货期（1-2周）
├── [B]开始耗尽，[A]悄悄积累
├── R指数飙升→快速回落（最后一批接盘者入场）
├── 对应数据：机构席位开始净卖出，北向资金流出
└── N信号：利好出尽，负面消息开始涌现

Phase 4: 回归期（1-4周）
├── [B]急剧下降，[A]主导
├── R指数跌至低位（<2），涨跌比<30%
├── 对应数据：机构净卖出加速，散户接盘
└── N信号：媒体开始反思/质疑
```

### 3.2 游资短周期（1-2周）

```
建仓(1-2天) → 拉升(1-2天) → 出货(1-2天) → 砸盘(1天)
```
游资周期短，龙虎榜上容易出现 **"一日游"营业部**（前一天大量买入，后一天大量卖出）。

### 3.3 国家队干预周期

```
护盘(1-3天) → 企稳(1-2周) → 退场(隐性的)
```
- 护盘信号：银行股、中字头异动，ETF份额突增
- 特征是：指数企稳但中小盘继续跌（结构性救市）

## 四、R指数 × [B]/[A] × 龙虎榜 交叉验证逻辑

### 4.1 状态矩阵

| R指数 | [B]-[A]盈余 | 龙虎榜机构行为 | 推断 |
|-------|-----------|--------------|------|
| **低 (<2)** | **负 (<-30%)** | 机构净卖出 | 恐慌踩踏中，不要接飞刀 |
| **低 (<2)** | **正 (>+30%)** | 机构净买入 | 逼空/加速上涨，注意见顶 |
| **高 (>5)** | **正 (>+30%)** | 机构净买入 | 分歧中机构在买入，可能是潜伏期 |
| **高 (>5)** | **负 (<-30%)** | 机构净卖出 | 分歧中被出贷，机构在降低风险敞口 |
| **温和(2-4)** | 接近0 | 无明显方向 | 垃圾时间，无操作价值 |
| **从高骤降** | 正转负 | 机构净转出 | ⚠️ 收割完成信号，清仓 |

### 4.2 异常模式识别

**模式A：机构密集买入但股价下跌**
- 持仓：机构在低位吸筹 → 中线看多
- 空仓：[B]没有跟上 → 短期可能继续跌，等R指数触底

**模式B：机构密集卖出但股价上涨**
- 持仓：⚠️ 机构在出货，散户和游资在接力 → 减仓
- 空仓：不追，等机构卖完再看

**模式C：机构/游资/北向三方一致**
- 无论方向 → 市场形成共识，可持续性最强
