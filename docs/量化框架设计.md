## 2. 多因子框架设计

### 待补拉信号数据

现有 `market_signals` 里的 lhb、margin、etf_share 都是基础，但缺少的几个关键信号需要补拉：

**高优先级：**
1. **龙虎榜详细**（买卖前5席位）— akshare `stock_sse_summary()` 类
2. **累计涨跌幅**（3日/5日/10日偏离值）
3. **北向资金十大成交股** — 个股级流入流出

**中优先级：**
4. **大宗交易** — akshare有 `stock_dzjy_mrmx()`
5. **限售解禁** — 用 `stock_jjz_gsrl()` 
6. **增减持** — `stock_ggcg()`

### 因子体系

```
┌─────────────────────────────────────────────────────────────┐
│                    多因子量化分析框架                         │
├─────────────┬─────────────┬──────────────┬──────────────────┤
│   Alpha因子  │  风险因子    │  特征因子     │  信号因子         │
├─────────────┼─────────────┼──────────────┼──────────────────┤
│ 动量因子     │ 行业因子     │ 市值因子      │ 两融变化          │
│ 反转因子     │ 货币周期因子  │ PE/PB估值     │ 北向资金流         │
│ 质量因子(ROE)│ 板块Beta因子 │ 换手率        │ ETF份额变化        │
│ 成长因子     │ 宏观利率因子 │ 波动率        │ 龙虎榜信号         │
│ 价值因子     │             │ 走势形态       │                   │
│             │             │ 均线乖离       │                   │
└─────────────┴─────────────┴──────────────┴──────────────────┘
```

#### 信号因子（最新补充方向）

从现有 market_signals 可以加工的：

1. **两融净买入** = 今日余额 - 昨日余额，是杠杆资金的情绪指标
2. **北向净买入** = north_buy - south_buy，外资态度
3. **ETF份额变化** = 看资金是流入还是流出宽基/行业ETF
4. **龙虎榜** = 识别游资/机构活跃度

## 3. 策略路线图

```

第1层 — 数据层（已完成）
  ↓
第2层 — 因子引擎（现在做）
  ├── 因子计算模块（从raw数据算因子值）
  ├── 因子标准化（去极值、中性化）
  └── 因子IC分析（评估因子有效性）
  ↓
第3层 — 策略层
  ├── 单因子策略（动量、反转、ROE选股）
  ├── 多因子综合打分
  └── 行业轮动信号
  ↓
第4层 — 回测与执行
  ├── 历史回测引擎
  ├── 风险归因（Barra风格/行业）
  └── 实盘监控面板
```
