## 二、核心模块详解

### 2.1 五路并行RAG

当前`deep_rag_search()`是单路语义检索。改造为5路并行，每路独立数据源和输出模板：

| 检索路 | 目的 | 数据源 | 输出模板 |
|--------|------|--------|----------|
| 1.事实基线 | 不可争议的硬数据 | FRED/AKShare/IEA/OPEC/EIA/UCDP/ACLED | 原始数值+单位+时间戳，禁止概括 |
| 2.多头论据 | 主流框架观点 | Exa学术搜索/Semantic Scholar/投行报告 | 核心假设+隐含前提+历史预测胜率 |
| 3.空头反共识 | 对立观点，打破确认偏误 | Seeking Alpha做空/CFTC净空头极值/学术批评 | "报告最可能出错的情景+触发条件" |
| 4.历史回测 | 统计替代拍脑袋类比 | JSTOR/NBER/SSRN/Reinhart-Rogoff数据库 | 定义参数+持续时间+资产回报分布 |
| 5.市场定价 | 当前价格内化的预期 | Finnhub期权IV/CDS利差/期货远月曲线/BDI | 市场定价-基本面公允值=风险溢价 |

**数据源复用矩阵**（已有→直接用）：

| 数据源 | 已有工具 | 覆盖路 |
|--------|----------|--------|
| FRED API | fetch_market.py + data_search._search_fred | 路径1 |
| AKShare | data_search._search_akshare | 路径1 |
| Finnhub | fetch_market.py | 路径5 |
| Exa | data_search._search_exa | 路径2 |
| Semantic Scholar | data_search.SemanticScholarLib | 路径2+4 |
| SerpAPI | data_search._search_serpapi | 路径3 |
| UCDP/ACLED | fetch_ucdp.py / fetch_acled.py | 路径1 |
| EIA | TOOLS.md有key | 路径1+5 |
| 财联社 | data_search._search_cls | 路径2 |

**缺少但可快速补充的**：

| 数据源 | 用途 | 获取方式 |
|--------|------|----------|
| CFTC COT持仓 | 反共识信号 | 免费API，写个fetch函数 |
| 期权IV曲面 | 市场隐含概率 | Finnhub已有部分覆盖 |
| CDS利差 | 信用风险情绪 | Finnhub Premium或TradingEconomics免费层 |
| Seeking Alpha做空 | 空头论据 | web_fetch抓取 |

### 2.2 专家委员会调度

**专家数据 = personality_v3.json（已有）**

不需要新建expert_profile.json。现有数据已包含：
- brief/school/domains → 框架定位
- cognitive_patterns/analytical_frameworks → 分析方法
- insights_with_evidence → 核心观点
- logical_tracing/evolution_trajectory → 思想逻辑
- decision_patterns/situational_triggers → 决策模式

**需补充的元数据**（自动提取，不手写）：
```json
{
  "prediction_style": "directional|point|conditional",
  "tone": "pessimistic|optimistic|neutral",
  "stance_bias": "hawk|dove|neutral",
  "framework_tags": ["offensive_realism", "deterrence_theory"],
  "historical_accuracy": null
}
```

这些可以从现有personality_v3.json用LLM批量提取，存入chromadb的metadata。

**匹配逻辑**：
```
议题 → LLM提取维度向量 → chromadb按维度×框架×立场检索 → 
每维度选2-3人（确保框架多样性）→ 至少1名反共识专家 → 委员会名单
```

### 2.3 多轮辩论引擎

**Round 1: 独立诊断**
```
System: [该专家的personality_v3摘要]
User: 给定议题[{topic}]和以下实时数据[{data_card}]，
     基于你的理论框架，给出：
     1. 核心判断（油价上限）
     2. 因果逻辑链
     3. 关键假设列表
     4. 如果假设X不成立，结论如何失效
     5. 对当前市场定价的评价
     
输出JSON: {judgment, logic_chain, assumptions[], 
          invalidation_conditions[], market_assessment}
```

**Round 2: 交叉质询**
```
System: [该专家的personality_v3摘要]
User: [另一专家]的诊断如下：[Round1输出]
     基于你的框架，指出其逻辑漏洞、忽视的变量、或假设的不合理之处。
     引用你自己的理论或实证依据。
```

**Round 3: 修正回应**
```
System: [该专家的personality_v3摘要]
User: [其他专家]对你的批评如下：[Round2输出]
     你是否修正你的判断？说明原因。
     如果坚持，给出进一步辩护。
```

**Round 4: 集成裁判**
```
System: 你是中立的"方法论审计员"。
User: 以下是N位专家的完整辩论记录：[所有Round输出]
     1. 收敛点（哪些判断所有/多数专家同意）
     2. 不可调和的分歧（分歧来源是什么：假设不同？理论内核不同？）
     3. 置信区间（收敛判断的共识强度）
     4. 集体盲区（所有专家都可能忽视什么）
     5. 对市场定价的集体评价（价格中包含多少叙事泡沫）
```

**辩论模式（按场景选择）**：

| 模式 | 专家数 | 轮数 | 耗时 | 适用场景 |
|------|--------|------|------|----------|
| 快速 | 5人 | 2轮 | 8-10分钟 | 日常简报、紧急事件 |
| 标准 | 10人 | 3轮 | 20-30分钟 | 周报、深度分析 |
| 完整 | 15人 | 4轮 | 40-60分钟 | 月度战略报告 |

### 2.4 蒸馏三工序（辩论后处理）

**工序一：结构化抽取**
从每条专家输出中提取：
- 主体（谁说的）/ 动作（预测/分析/批评）/ 对象（什么资产/变量）
- 数值（价格/概率/持续时间）/ 时间（短期/中期/长期）
- 框架名称 / 证据类型（统计回归/案例/专家判断）
- 立场标签（多头/空头/中性）

**工序二：交叉矛盾检测**
```
冲突矩阵：
- 事实vs观点：专家说"库存充足"vs IEA数据显示"降至5年低点" → 事实-观点冲突
- 专家vs专家：Mearsheimer预测$200 vs Dalio预测$140 → 分歧来源标注
- 专家vs市场：多数专家看$150+ vs 期权隐含$180+概率仅15% → 定价差距标注
- 多头vs空头：路2说"持续升级" vs 路3说"封锁能力衰减" → 多空冲突
```

**工序三：可证伪性封装**
每条预测自动附加：
```
预测：布伦特将在3个月内触及$150
证伪条件：如果海峡日均通行量恢复至>1000万桶/日持续2周，则此预测失效
数据源：Vortexa/AIS船舶追踪（或IEA周报替代）
```

### 2.5 数学建模

**四种最小可行模型**：

| 模型 | 输入 | 输出 | 参数来源 |
|------|------|------|----------|
| 供需弹性缺口 | 中断量+库存天数+需求弹性 | 中断%→均衡价格查表函数 | Hamilton 2003实证 |
| 贝叶斯生存分析 | 冲突持续先验+每日事件 | 实时"未来30天停火概率" | UCDP历史冲突数据 |
| 情绪→波动率回归 | 新闻情绪分+VIX | 情绪定价过度/不足判断 | Ollama+FinBERT本地 |
| 监管压力指数 | 听证会频次+罚款+法案概率 | 可回测风险指数 | 按议题定制 |

**回测要求**：
- 用至少2个历史案例跑模型（如1973禁运+1990海湾战争）
- 如果模型显著高估/低估，按偏差比例校准当前预测
- 输出强制包含：乐观/基准/悲观三种推导+参数敏感度排序

### 3.2 调度器规则

**规则1：反共识即时抓取**
- 触发：模型预测上涨 → 自动抓Seeking Alpha做空报告+CFTC净空头变化
- 强制：反方观点附在每日简报末尾

**规则2：数据日历驱动**
- 不按时间线性触发，按"即将发布数据的破坏力"触发
- CPI/FOMC/EIA库存周报发布前24h → 扩大置信区间 + 暂停点预测
- 维护一个宏观数据发布日历

**规则3：横截面验证**
- 模型预测"地缘风险→油价涨" → 立即交叉验证：
  - 航运保费涨了吗？
  - 远月期货深度贴水了吗？
  - 产油国CDS利差扩大了吗？
- 任意一个不成立 → 标注"模型发散警告"，冻结交易建议

## 四、Prompt第一性指令

任何报告生成的最高优先级system指令：

```
1. 禁用形容词，只输出操作符
   ❌ "油价将大幅上涨"
   ✅ "触发条件：海峡通行<500万桶/日持续2周 → 做多Brent，目标$160，止损$105"

2. 只承认可被证伪的预测
   每个判断必须附带："如果下周发生___，则以上判断立即作废"

3. 强制溯源+历史胜率
   引用Mearsheimer时标注：该框架对1990后中东大规模战争的预测命中率~60%
   （框架胜率数据库需长期积累，初期用已知论文数据填充）

4. 数学推导优先于直觉
   给出数值时必须展示计算过程：供需缺口×弹性系数=价格变化
   不允许"基于综合判断我们认为..."

5. 偏差审计必须闭环
   识别偏差后必须修正结论，不允许"审计归审计，结论归结论"
```
