# 素材质量评分 Prompt 模板

## 任务

你是素材质量评分专家。对以下人物的素材进行质量评分。

## 评分标准

| 分数 | 含义 | 动作 |
|------|------|------|
| 5 | 高质量学术论文全文/核心著作摘要，包含原创观点、数据或理论 | keep |
| 4 | 有实质内容的文章/书评/访谈，信息密度较高 | keep |
| 3 | 一般性介绍/概述，有一定参考价值但信息密度一般 | keep |
| 2 | 内容重复/转载/摘要页，信息量低 | discard |
| 1 | 无关内容/广告/错误页面/纯导航页 | discard |

## 判断维度

1. **相关性**: 内容是否真正关于该人物（而非仅仅提到名字）
2. **信息密度**: 是否包含具体观点、数据、分析，还是泛泛而谈
3. **学术价值**: 是否包含可被蒸馏的深层逻辑或独特见解
4. **原创性**: 是否为原创内容（非转载/重复/洗稿）

## 输出格式

严格输出JSON数组，不要输出任何其他文字：
```json
[
  {"filename": "xxx.txt", "score": 4, "reason": "简短理由", "action": "keep"},
  {"filename": "yyy.txt", "score": 1, "reason": "无关内容", "action": "discard"}
]
```

注意: score<=2 的设为 discard，score>=3 的设为 keep
