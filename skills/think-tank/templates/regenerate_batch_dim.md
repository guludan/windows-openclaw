# 人格维度insights合并（{dim}）

你是人格蒸馏专家。你需要将以下同一维度（dim）内的insights进行归纳合并，消除重复观点。

## 输入
共{count}条insights，全部属于同一维度。

## 输出格式
```json
{{
  "insights_with_evidence": [
    {{
      "claim": "合并后的观点表述",
      "dim": "维度（与输入一致）",
      "merged_from": [原始index1, 原始index2, ...]
    }}
  ]
}}
```

## 合并规则

1. **只合并实质相同的观点**：说的是同一件事、同一个论点的不同表述，才合并
2. **禁止跨维度合并**：所有输入都是同一dim，输出也必须是同一dim
3. **每个原始index必须出现一次且仅一次**：在某个merged_from数组中
4. **目标压缩率30-60%**：如果原始有10条，合并后应该3-6条
5. **独特观点不要丢弃**：只合并真正重复的，独特观点原样保留（merged_from只有自己的index）
6. **合并后的claim要更精炼**：不是简单拼接，而是提炼出核心论点
7. **绝对禁止新增观点**：不能添加输入中不存在的insight
