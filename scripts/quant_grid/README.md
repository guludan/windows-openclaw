# 量化网格交易系统

基于腾讯API（零鉴权、不封IP）的A股自动买卖框架。

## 核心理念

机构的操作指纹：
1. **控制股价上浮区间** → 设定区间上限，到价就压盘
2. **控制股价下跌区间** → 设定区间下限，到价就接盘
3. **制造恐慌出清** → 快速砸盘逼散户割肉
4. **低位吸筹** → 散户割完后慢慢吃

散户的反操作：网格化自动买卖，用机构的规则反制机构。

## 系统架构

```
tencent_intraday.py    — 数据层（分时/分钟/日K/实时行情）
grid_trader.py         — 策略执行层（网格上下限+信号判断）
trade_log.py           — 交易记录层（PG+本地双记录）
```

## 数据源（腾讯API）
- 实时行情: qt.gtimg.cn（PE/PB/量比/5档盘口）
- 当日分时: ifzq.gtimg.cn/appstock/app/minute/query
- 分钟K线: ifzq.gtimg.cn/appstock/app/kline/mkline
- 日K线: web.ifzq.gtimg.cn/appstock/app/fqkline/get

## 网格参数（示例：嘉化600273）

```
当前价: 6.80
网格间距: 1%
仓位: 200股
单格买卖: 50股
止损线: -10%（从成本）
上下限: 根据波动率自动调整
```

## 情绪诊断模块

```
输入：用户对话 → 提取情绪特征
输出：当前处于机构博弈的哪个阶段
- phase 1: 机构建仓期 → 耐心HOLD
- phase 2: 机构拉升期 → 分批卖出
- phase 3: 机构砸盘期(当前) → 网格接货
- phase 4: 机构洗盘期 → 不动或小T
- phase 5: 散户恐慌期 → 反收割买入
```
