### 策略集总结（三只股票通用）

| 策略编号 | 名称 | 特征 | 目的 |
|:-------:|------|------|------|
| S0 | **缩量横盘** | 全天0.5%以内波动，量<均值70% | 测试散户耐心，看会不会自己走 |
| S1 | **开盘杀** | 09:30-09:45快速砸1-2% | 制造开盘恐慌 |
| S2 | **时间窗口砸** | 10:45-11:00砸到全天低点 | 活跃度最高+散户心态最弱时出手 |
| S3 | **午后回落** | 13:00-14:30缓慢往下推 | 测试午后是否有人接盘 |
| S4 | **尾盘拉升** | 14:30-15:00拉到开盘价附近 | 给散户留希望，不清仓 |
| S5 | **全面杀跌** | 全天连续砸（今天嘉化的模式） | 全面测试止损线 |

### 每一天是"策略集"中的组合

```
6/9 嘉化: S0+S3                → 磨耐心+午后压
6/10 嘉化: S1+S3+S4           → 开盘杀+午后压+尾盘留希望
```

**轮换方式：** 每天随机组合。但今天三只股票同时用了S2（10:45时间窗口），说明这个时间段是全市场程序同步执行的。

## 反制执行方案

### 核心原则
- **不赌方向**（不猜他们会涨会跌）
- **只吃波动**（在已知的策略窗口内做反方向操作）
- **纪律第一**（到了价格就执行，不管"感觉"）

### 每天固定窗口（收盘后设定，第二天盘中执行）

```
09:30-09:45  — S1窗口（开盘杀）
  操作：如果低开>1% + 量比>1.5 → 挂低1%接50股
  如果正常开盘 → 不操作

10:40-10:55  — S2窗口（时间窗口砸）
  操作：10:40拉一次实时价
  如果比开盘价跌了>2% → 挂当前价-0.5%接50股
  如果没跌 → 不操作

14:30-15:00  — S4窗口（尾盘拉升）
  操作：如果下午最低比早上低点还低 → 尾盘不操作（可能有S5）
  如果下午稳住了 → 14:45后把上午买的抛掉
```

### 转天开盘前的检查清单

```
□ 昨天收盘价在网格范围内？
□ 昨天用的策略是哪个？（S1? S2? S5?）

□ 昨晚有政策/消息面变化？
□ 网格参数是否需要调整（根据昨日振幅）？
```
